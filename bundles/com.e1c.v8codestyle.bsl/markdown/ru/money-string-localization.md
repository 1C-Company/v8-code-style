# Денежные поля: требования по локализации

При использовании в конфигурации Библиотеки стандартных подсистем не следует использовать конструктор типа Число 
для получения описания типа денежного поля. Вместо этого использовать функцию, возвращающую описание на основании 
определяемого типа.

## Неправильно

ОписаниеТиповСумма = Новый ОписаниеТипов("Число", Новый КвалификаторыЧисла(15,2));

## Правильно

ОписаниеТиповСумма = РаботаСКурсамиВалют.ОписаниеТипаДенежногоПоля();
