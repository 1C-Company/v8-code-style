# Однократный обработчик ожидания в обработчике ПриАктивизацииСтроки

Клиентский обработчик события `ПриАктивизацииСтроки` (`OnActivateRow`) вызывается синхронно при каждой
активизации строки. Выполнение серверных вызовов прямо в этом обработчике приводит к синхронным серверным
вызовам и повторным запросам при перемещении пользователя по строкам списка.

Вместо этого в обработчике следует подключать однократный обработчик ожидания (`ПодключитьОбработчикОжидания`
с параметром однократности, равным `Истина`), а серверные вызовы размещать в процедуре этого обработчика
ожидания. Подключение обработчика ожидания откладывает вызовы до завершения события, а однократный режим
исключает повторные вызовы при последующих активизациях строк.


## Неправильно

```bsl
&НаКлиенте
Процедура ПриАктивизацииСтроки(Элемент, Строка)
	ОбработатьСтроку(Элемент, Строка);
КонецПроцедуры
```

```bsl
&НаКлиенте
Процедура ПриАктивизацииСтроки(Элемент, Строка)
	ПодключитьОбработчикОжидания("ОбработчикОжидания", 1, Ложь);
КонецПроцедуры
```

```bsl
&НаКлиенте
Процедура ПриАктивизацииСтроки(Элемент, Строка)
	ПодключитьОбработчикОжидания("ОбработчикОжидания", 1, Истина);
	СерверныйВызов();
КонецПроцедуры
```

## Правильно

```bsl
&НаКлиенте
Процедура ПриАктивизацииСтроки(Элемент, Строка)
	ПодключитьОбработчикОжидания("ОбработчикОжидания", 1, Истина);
КонецПроцедуры

&НаКлиенте
Процедура ОбработчикОжидания()
	СерверныйВызов();
КонецПроцедуры
```
