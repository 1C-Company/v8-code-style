# Обновление списков при интерактивных действиях пользователя

Если в клиентской процедуре в модуле формы идет вызов серверной процедуры, в которой происходит изменение объекта посредством вызова Записать(), Удалить() или УстановитьПометкуУдаления(), то в клиентской процедуре должен быть вызов процедуры Оповестить() или ОповеститьОбИзменении().

## Неправильно
```bsl
&НаКлиенте
Процедура Неправильно()

	ИзменитьОбъектНаСервере();
	
КонецПроцедуры

&НаСервере
Процедура ИзменитьОбъектНаСервере()

	// Код ...

	Записать();

КонецПроцедуры
```

## Правильно

```bsl
&НаКлиенте
Процедура Неправильно()

	ИзменитьОбъектНаСервере();
	
  	Оповестить("Запись_РасходнаяНакладная", ПараметрыЗаписи, Объект.Ссылка);

КонецПроцедуры

&НаСервере
Процедура ИзменитьОбъектНаСервере()

	// Код ...

	Записать();

КонецПроцедуры
```
