# Отступы в секции описание метода

Текст в объявляемых секциях комментария должен иметь отступ относительно заголовка секции.

Если описание состоит из нескольких строк, дополнительный отступ ставится только у второй строки. Все следующие строки должны быть выровнены по второй строке.

Если внутри секции начинается новый уровень вложенности, его строки должны иметь одинаковый отступ. Поэтому большой отступ у первой строки не является ошибкой, если остальные строки этого же уровня имеют такой же отступ.

Для секций «Пример» и «Варианты вызова» действует отдельное правило: вторая и последующие строки имеют только один дополнительный отступ.

## Неправильно

```bsl
// Описание процедуры
//
// Параметры:
//   Параметр1 – Тип1 - первая строка описания параметра,
//   Вторая строка (ошибка)
//     Третья строка
//   Параметр2 – Тип2 - здесь начинается новый контекст.
//		 Вторая строка
//			Третья строка (ошибка)
//   	 Параметр3 – Тип2 - здесь начинается новый контекст. (ошибка)
//
Процедура Неправильно(Параметр1, Параметр2, Параметр3)
	
КонецПроцедуры
```

## Правильно

```bsl
// Первая строка описания универсальной процедуры.
// Вторая строка пишется без отступа, т.к. секция «Описание» не объявляемая.
// Третья и последующие строки пишутся без отступа.
//
// Параметры:
//   Параметр1 – Тип1 - первая строка описания параметра,
//     Вторая строка имеет смещение по отношению к первой.
//     Третья строка пишется без дополнительного смещения.
//   Параметр2 – Тип2 - здесь начинается новый контекст.
//		 Вторая строка
//		 Третья строка
//   Параметр3 – Тип2 - здесь начинается новый контекст.
//
Процедура Правильно(Параметр1, Параметр2)
	
КонецПроцедуры
```
