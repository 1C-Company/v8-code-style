# Передача данных формы по значению на сервер

Объекты данных формы (`ФормаДанныеСтруктура`, `ФормаДанныеКоллекция`, `ФормаДанныеСтруктураИКоллекция`,
`ФормаДанныеДерево`, `ТабличныйДокумент`) не следует передавать по значению в параметрах внеконтекстного
серверного вызова с клиента.

Такие объекты всегда передаются на сервер целиком, независимо от того, какая их часть фактически нужна.
При передаче в внеконтекстный серверный вызов (`&НаСервереБезКонтекста`) выполняется сериализация и отправка
всего объекта, что снижает производительность. Если объект данных формы требуется обработать на сервере, это
следует делать явным контекстным серверным вызовом (`&НаСервере`), либо передавать во внеконтекстный вызов
только минимально необходимые данные вместо объекта целиком.

## Неправильно

```
&НаКлиенте
Процедура КоличествоОтмененныхСтрокЗаказа()
  КоличествоСтрок = ОбщийМодульВызовСервера.КоличествоОтмененныхСтрок(Объект.Товары);   // Неоптимальная передача на сервер табличной части "Товары"
КонецПроцедуры

// Общий серверный модуль ОбщийМодульВызовСервера

Функция КоличествоОтмененныхСтрок(ТабличнаяЧасть);
  НайденныеСтроки = ТабличнаяЧасть.НайтиСтроки(Новый Структура("Отменено", Истина));
  Возврат НайденныеСтроки.Количество();
КонецФункции
```

## Правильно

```
&НаКлиенте
Процедура КоличествоОтмененныхСтрокЗаказа()
  КоличествоСтрок = КоличествоОтмененныхСтрок(); // Передача табличной части "Товары" выполняется неявно платформой, оптимально
КонецПроцедуры

&НаСервере
Процедура КоличествоОтмененныхСтрок()
  Возврат ОбщийМодульВызовСервера.КоличествоОтмененныхСтрок(Объект.Товары); // вызов "сервер"-"сервер" без доп. накладных расходов
КонецПроцедуры

// Общий серверный модуль ОбщийМодульВызовСервера

Функция КоличествоОтмененныхСтрок(ТабличнаяЧасть);
  НайденныеСтроки = ТабличнаяЧасть.НайтиСтроки(Новый Структура("Отменено", Истина));
  Возврат НайденныеСтроки.Количество()
КонецФункции
```
