# Вызов процедуры ФоновыеЗадания.Выполнить

Вызывать процедуру ФоновыеЗадания.Выполнить не рекомендуется при использовании БСП в конфигурации
Рекомендуется вместо этого использовать методы из БСП ДлительныеОперации.ВыполнитьВФоне, ДлительныеОперации.ВыполнитьФункцию, ДлительныеОперации.ВыполнитьПроцедуру и т.д.

## Неправильно

```bsl
РезультатФункции = ФоновыеЗадания.Выполнить(
	"МоиСерверныеПроцедуры.ВыполнитьДлительныйРасчет", 
	ПараметрыЗапуска, 
	КлючЗадания, 
	"Расчет данных по документу"
);
```

## Правильно

```bsl
РезультатФункции = ДлительныеОперации.ЗапуститьВыполнениеВФоне(
    "МоиСерверныеПроцедуры.ВыполнитьДлительныйРасчет", 
    ПараметрыПроцедуры, 
    ПараметрыВыполнения
);
```
