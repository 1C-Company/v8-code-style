# Определение типа значения переменной

Определение типа значения переменной должно производиться путем сравнения его с заданным типом, а не каким-либо другим методом.

## Неправильно

Например, неправильно:

Если Ссылка.Метаданные().Имя = "ПоступлениеТоваровУслуг" Тогда

## Правильно

Например, правильно:

Если ТипЗнч(Ссылка) = Тип("ДокументСсылка.ПоступлениеТоваровУслуг") Тогда
