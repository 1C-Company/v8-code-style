# Секция возвращаемого значения документирующего комментария содержит корректные типы коллекций.
# Если параметр возврата описывается как коллекция, но сам тип параметра коллекцией не является - это считается ошибкой.

## Неправильно

```bsl

// Возвращаемое значение:
//  Строка:
//      * Ключ1 - Строка
Функция Неправильно(Параметры) Экспорт
    // пустая
КонецФункции

```

## Правильно

```bsl

// Возвращаемое значение:
//  Структура:
//      * Ключ1 - Строка
Функция Неправильно(Параметры) Экспорт
    // пустая
КонецФункции

```
