# Секция возвращаемого значения документирующего комментария содержит корректные типы коллекций

## Неправильно

```bsl

// Возвращаемое значение:
//  Строка:
//      * Ключ1 - Строка
Функция Неправильно(Параметры) Экспорт
    // пустая
КонецФункции

```

## Правильно

```bsl

// Возвращаемое значение:
//  Структура:
//      * Ключ1 - Строка
Функция Неправильно(Параметры) Экспорт
    // пустая
КонецФункции

```
