# Отступы в документирующем комментарии

В комментарии не должно быть отступов использующих одновременно табуляцию и пробелы

## Неправильно

```bsl
//	 На данной строке отступ содержит символ табуляции и пробел одновременно (ошибка)
//
//  Параметры:
//   Параметр1 – Тип1 - описание
//		 На данной строке отступ содержит два символа табуляции и пробел одновременно (ошибка)
//   Параметр2 – Тип2 - описание
//		 Вторая строка
Процедура Неправильно(Параметр1, Параметр2)
	
КонецПроцедуры
```

## Правильно

```bsl
//  На данной строке отступ содержит два пробела
//
//  Параметры:
//   Параметр1 – Тип1 - описание
//		На данной строке отступ содержит два символа табуляции
//   Параметр2 – Тип2 - оипсание
//		 Вторая строка
Процедура Правильно(Параметр1, Параметр2)
	
КонецПроцедуры
```
