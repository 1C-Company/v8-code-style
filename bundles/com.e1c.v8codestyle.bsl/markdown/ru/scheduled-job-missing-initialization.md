# Вызов инициализирующей процедуры в методе регламентного задания

Если в конфигурации используется БСП, рекомендуется вызывать процедуру ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания() в начале метода регламентного задания.


## Неправильно

```bsl
Процедура Неправильно() Экспорт
	
	// нету вызова ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания()
	
	// какой-то код ...
	
КонецПроцедуры
```

## Правильно

```bsl
Процедура Правильно() Экспорт
	
	ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания(Метаданные.РегламентныеЗадания.МойРегламентныйОбмен);
	
	// какой-то код ...
	
КонецПроцедуры
```
