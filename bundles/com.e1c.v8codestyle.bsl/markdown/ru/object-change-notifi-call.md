# Обновление списков при интерактивных действиях пользователя

В форме объекта в событии ПослеЗаписи должен быть вызов процедуры Оповестить("Запись_ххх")
Проверка смотрит вызовы оповещения в рамках одного обработчика

## Неправильно

Процедура ПослеЗаписи(ПараметрыЗаписи)

КонецПроцедуры

## Правильно

&НаКлиенте
Процедура ПослеЗаписи(ПараметрыЗаписи)
  Оповестить("Запись_РасходнаяНакладная", ПараметрыЗаписи, Объект.Ссылка);
КонецПроцедуры
