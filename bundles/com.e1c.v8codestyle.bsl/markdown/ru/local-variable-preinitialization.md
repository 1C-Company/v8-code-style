# Предварительная инициализация локальных переменных

Проверка осуществляет поиск переменных, которые не были инициализированы в рамках текущего блока или на более высоких (родительских) уровнях вложенности.

## Неправильно

```bsl
Процедура Неправильно()

	Если 1 = 1 Тогда
		А = 1;
	КонецЕсли;
	
	Б = А;

КонецПроцедуры
```

## Правильно

```bsl
Процедура Правильно()
	
	А = 0;

	Если 1 = 1 Тогда
		А = 1;
	КонецЕсли;
	
	Б = А;

КонецПроцедуры
```
