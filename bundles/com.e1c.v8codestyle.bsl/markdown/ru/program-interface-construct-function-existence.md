# Структуры и таблицы значений в качестве параметров процедур и функций

В программном интерфейсе должна быть функция-конструктор возвращающая структуру-заготовку со свойствами или пустую таблицу значений (дерево значений) с типизированными колонками.
Проверка смотрит на возвращаемый тип функции, у функции-конструктора он должен быть либо Структура, либо ТаблицаЗначений, либо ДеревоЗначений.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

// нету функции-конструктора

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

Функция ПараметрыЗаполненияЦеныВСтрокеТЧ() Экспорт
 
 ПараметрыЗаполненияЦен = Новый Структура;
 ПараметрыЗаполненияЦен.Вставить("Дата", ТекущаяДатаСеанса());
 ПараметрыЗаполненияЦен.Вставить("Валюта", ОсновнаяВалюта());
 ПараметрыЗаполненияЦен.Вставить("ПересчитыватьСумму", Истина);
 Возврат ПараметрыЗаполненияЦен;
 
КонецФункции

#КонецОбласти
```
