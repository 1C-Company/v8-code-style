# Ограничения при использовании динамических списков

Для иерархических списков не рекомендуется устанавливать свойство НачальноеОтображениеДерева в значение РаскрыватьВсеУровни, так как это приведет к критичному снижению скорости открытия больших списков. Следует  использовать значения НеРаскрывать или РаскрыватьВерхнийУровень.

## Неправильно

В иерархическом списке задавать свойству НачальноеОтображениеДерева значения РаскрыватьВсеУровни

## Правильно

В иерархическом списке задавать свойству НачальноеОтображениеДерева значения НеРаскрывать или РаскрыватьВерхнийУровень
