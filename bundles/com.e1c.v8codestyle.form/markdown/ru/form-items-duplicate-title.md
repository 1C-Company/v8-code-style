# Повторяющиеся заголовки элементов формы

Проверка находит элементы формы одного типа — кнопки и группы — с одинаковым заголовком в пределах одного контекста.
Контекстами считаются сама форма, командная панель, подменю и контекстное меню.

## Неправильно

```
Форма
 Группа "Действия"
 Группа "Настройки"
 Группа "Действия" // заголовок повторяет первую группу
```

## Правильно

```
Форма
 Группа "Действия"
 Группа "Настройки"
```
